# UI/UX Internship Portfolio

Original project brief: UI/UX Food Ordering App Design using Figma.

This project is a portfolio website for the UI/UX internship at InternPe from 25 May 2026 to 19 July 2026. It contains one home page and seven responsive design task pages created in plain HTML, CSS, and JavaScript.

## Project structure

- `index.html` — portfolio home page
- `css/` — shared and page-specific styles
- `js/` — shared and page-specific scripts
- `pages/` — design task pages
- `assets/images/` — placeholder image folder

## How to run

1. Open the folder `uiux-internship-portfolio` in VS Code.
2. Install the Live Server extension in VS Code.
3. Right-click `index.html`.
4. Select `Open with Live Server`.
5. The portfolio will open in your browser.

## Deploy to Vercel

Import the project repository in Vercel and make sure the project's **Root Directory** is the folder that directly contains `index.html` and `vercel.json`. If the repository contains this project inside a `uiux-internship-portfolio` subfolder, set Root Directory to `uiux-internship-portfolio`; if the repository itself contains these files at its top level, leave Root Directory at `.`. Use the **Other** framework preset and leave build commands empty. Then redeploy.

## Pages included

- Food App — mobile menu and cart interface
- E-commerce Website — store homepage, product modal, and checkout flow
- Email Newsletter — responsive email layout with visitor preview toggles
- Coffee Shop UI — ordering, customization, payment, and loyalty experience
- Game Shop — gaming catalog and checkout flow
- Newspaper — editorial page with a dark mode toggle
- Instagram Clone — social app screens for home, explore, reels, and profile

## Notes

- The project uses mobile-first responsive layout techniques.
- All assets use remote Unsplash/Picsum placeholder images.
- The website is designed to be fast, accessible, and easy to modify.
